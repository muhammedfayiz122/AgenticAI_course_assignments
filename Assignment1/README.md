# 🛍️ Product Assistant Bot

An AI-powered assistant using LangChain + Groq to give product informations. Access via CLI or Streamlit UI.

## 🚀 Demo
[Live Streamlit App](https://agenticaicourseassignments-df6wfk73jkwrapqwgut6yk.streamlit.app/)

## 📦 Setup
```bash
git clone https://github.com/your-username/product-assistant-bot.git
cd product-assistant-bot
pip install -r requirements.txt
```

Create `.env` file:
```
GROQ_API_KEY=your_key
LANGSMITH_API_KEY=your_key
LANGSMITH_PROJECT=your_project
```

## 🧪 Run
**CLI:**
```bash
python product_assistent_bot.py
```
**Streamlit UI:**
```bash
streamlit run app.py
```

## 📁 Files
- `product_assistent_bot.py` – LangChain logic
- `app.py` – Streamlit frontend
